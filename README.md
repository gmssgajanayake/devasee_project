# Online Book Sales & Printing Management Platform

## 📌 Overview
A production-ready online platform developed for Devasee Pvt Ltd to manage book sales,
custom printing orders, and operational workflows. The system supports secure user
authentication, order management, and scalable deployment for real-world usage.

This project was developed as a Final Year Software Engineering project, with a strong
focus on clean architecture, security, and production readiness.

## 🚀 Key Features
- User authentication and role-based access control (Admin, Staff, Customer)
- Online book catalog and order management
- Printing request and workflow handling
- Secure RESTful APIs with JWT authentication
- SEO integration and production optimization
- Cloud-based deployment and scalability

## 🛠️ Tech Stack
- Backend: Java 11, Spring Boot, Spring Security, JWT
- Frontend: Next.js
- Database: PostgreSQL
- Cloud & Deployment: Azure, Cloudflare, Vercel
- SEO & Monitoring: Google Search Console
